# Rajarata Digital Banking Application

This project serves as a digital banking application providing various banking services. It aims to enhance user experience through a secure and easy-to-navigate platform.

## Features
- User Management
- Account Management
- Transaction Processing
- Loan Management
- Bill Payments

## Technologies Used
- Java
- Spring Framework
- Maven
- JUnit

## Getting Started

### Prerequisites
- Java 8+
- Maven

### Installation
1. Clone the repository
   ```bash
   git clone https://github.com/ranaweera777/rajarata-digital-banking.git
   ```
2. Navigate into the directory
   ```bash
   cd rajarata-digital-banking
   ```
3. Build the project
   ```bash
   mvn clean install
   ```

## Usage
- To run the application
  ```bash
  mvn spring-boot:run
  ```
